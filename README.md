# 我们的纪念日网页

这是一个可直接在浏览器中打开的静态网页，适合保存为个人纪念日页面。

## 运行方式

1. 下载本仓库内容。
2. 打开 `index.html` 即可浏览。
3. 如需部署到 GitHub Pages，可在仓库设置中启用 Pages，选择根目录即可。

## 可自定义内容

- 替换 hero 区域的照片
- 改写时间线事件
- 替换聊天记录内容
- 替换照片墙图片
- 修改文案中的名字/地点/纪念日信息

## 说明

网页默认使用了 Unsplash 的在线图片资源，因此只要有网络即可正常显示。
如果你想直接使用自己的本地图片，可把对应的图片地址替换为你的本地文件路径或上传到仓库中的 `assets` 目录后引用。
